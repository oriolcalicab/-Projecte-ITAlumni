## Description

This project is a set of static pages (HTML/CSS) with TypeScript/JavaScript code running alongside the browser. It includes:

- Landing principal (`index.html`)
- Networking page (`page/networking.html`)
- Job portal page “Oportunitats de feina” (`page/jobPortal.html`)
- Registration page (`page/signup.html`)

## Project structure

- `index.html` — home page (hero, serveis, testimonials, footer)
- `page/` — secondary pages
  - `jobPortal.html`
  - `networking.html`
  - `signup.html`
- `src/`
  - `assets/` — images and icons
  - `css/` — styles
    - `style.css` (global)
    - `jobPortal.css`, `networking.css`, `signup.css`
  - `js/` — JS automatically compiled from the folder`ts/` (includes sourcemaps)
    - `jobPortal.js`, `networking.js`, `signup.js`
  - `ts/` — codi TypeScript font handwritten
    - `jobPortal.ts`, `networking.ts`, `signup.ts`

## Technologies and Methodology

- **Frontend:** HTML5, CSS3 (Grid i Flexbox), JavaScript Modern / TypeScript.
- **Persistence:** `localStorage` (to save offers and users in plain text JSON).
- **Version control:** Gitusing the methodology **Gitflow** (`main`, `develop` and branch `feature/`).
- **Cleaning:** Use of `.gitignore`to exclude large files (`node_modules/`) or duplicates generated by the compiler.

## Functionalities Core (TypeScript)

### 💼 Job Portal (oportunitats de feina)

Main implementation in: `src/ts/jobPortal.ts`.

***Tipus de dades:** `interface Job` (id, titol, tipusContracte, publicat, imatgeUrl, esPopular, esJunior, diesEnrere).
***Operation flow:**

  1. **Workload**: `carregarFeinesPortal()`. Read from `localStorage`. If empty, inject data *mock* initials and save them.
  2. **Render the grid**: `renderitzarFeines(llistaFeines)`.It creates dynamic HTML structures and injects them into`#job-grid`. Unify all action buttons with the text "View Details".
  3. **Search engine**: Filter in real time using the `input` event of the `#search-job` element by title or contract type.
  4. **Selection filters**: Listens to the click on `.filter-link`, dynamically handles the `.active` CSS class, and applies filters:
     - **"Activitat recent"**: ordena per `diesEnrere` in ascending order.
     - **"Popular"**: filter featured jobs (`esPopular === true`).
     - **"Junior"**: filter jobs for entry-level profiles (`esJunior === true`).

### 🌐 Networking (Xarxa d'Alumnes)

Main implementation in: `src/ts/networking.ts`.

- Parallel logic for loading and mapping registered student information.
- Filtres avançats utilitzant el mètode `.sort()` i `localeCompare()` to sort profiles alphabetically by first name, last name or newest(ID).

## Data persistence

Offers are saved in the browser with:

- Key: `feines`
- Format: Format: JSON array of `Job' objects.

## How to execute the project

### 1. Code compilation (TypeScript)

Before opening the project, you need to compile the files from the `src/ts/` folder into `src/js/` using the configuration set in `tsconfig.json`.

Run in the terminal of the project root:

```bash
# Leave the compiler in active listening mode (Watch)
tsc -w
```
